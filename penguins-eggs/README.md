# penguins-eggs

```bash
sudo ./penguins-eggs/install.sh
```

Installer dependencies: Bash, curl, standard system utilities and the native
package manager (apt-get, dnf, zypper, pacman or apk, depending on the distro).
The package manager resolves the package's runtime dependencies.
No Node.js runtime or Go compiler is required by this installer.

Downloads the latest compatible non-legacy package from the basket.
